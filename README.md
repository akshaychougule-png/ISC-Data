# ISC Data — Technical Documentation

A docs.cognite.com-style reference page for Cognite's Integrated Supply Chain (ISC) offering, covering:

- Hierarchy architecture (dedicated trees, core fields, automated sync, strongly typed hierarchies)
- Data model & domains (the 10 schema-space domains, nodes vs. typed edges)
- Agents & tools (Atlas AI agents, grounding/escalation skills, custom tools)

Built from and verified against [cognitedata/Beyond-The-Plant-Model](https://github.com/cognitedata/Beyond-The-Plant-Model).
